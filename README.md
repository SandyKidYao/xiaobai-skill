# xiaobai skill(小白)

一个用于优化 AI 输出方式的 Agent SKILL:避免一次性输出长文,改为小步交互。由三种交互范式和两个工具组成。

**交互范式:**

- **分步指导**:指导用户完成工作时,先给简要路线图,然后一步一步带着做,每步可实操、可验证,根据用户反馈继续。
- **QA 快问快答**:完成复杂工作后,不输出冗长报告,而是结论先行 + 推荐问题,通过快问快答帮用户逐步理解全貌。
- **HTML 讲解页**:讲解 diff/PR/代码时,生成"背景 → 直觉 → 代码 → 测验"结构的自包含 HTML 讲解页,先建立心智模型再看实现。做一般汇报和内容展示时,同样优先生成带图表、可交互的 HTML 页面替代大段文字。

**工具**(任何范式下都可以使用):

- **Quiz**:精心设计的测验,帮用户检验自己是否真的理解了——QA 帮用户建立认知,Quiz 帮用户巩固认知。
- **交互式架构报告**:阐述软件系统整体架构与设计时,生成可交互的架构图与报告。
